# Skill 清单

下列本地 Skill 由此仓库统一维护；只有明确标作候选的外部链接尚未部署。来源和本地适配见 [SOURCES.md](SOURCES.md)。

## 通用

- [场景与模式协作](skills/scene-mode-collaboration/SKILL.md)：按场景和模式推荐分工、Skill 与人机交接点。
- [grill-me](skills/grill-me/SKILL.md) 与依赖 [grilling](skills/grilling/SKILL.md)：AI 主导追问。

## 工程

- [STS](skills/stop-that-shit/SKILL.md)、[STSS](skills/stss/SKILL.md)：每任务由人工明确点名（`$stop-that-shit`、`$stss`）后使用，控制范围与精简决策文稿。
- [reviewing-code-modularity-skill](skills/reviewing-code-modularity-skill/SKILL.md)：大规模开发时检查模块边界与结构。
- [improve-codebase-architecture](skills/improve-codebase-architecture/SKILL.md)：按需扫描架构摩擦并讨论维护改造。

## 科研

- [research-cycle](skills/research-cycle/SKILL.md)：串联问题、证据、假说、软件实验、分析、对抗复核与论文／报告；按任务分工，允许身兼多职。
- [paper-lookup](skills/paper-lookup/SKILL.md)：可追溯的论文检索、查新与来源核对。
- [hypothesis-generation](skills/hypothesis-generation/SKILL.md)：形成可检验假说与替代解释；穷举模式允许提出临时探索优先级，最终科学判断交给人。
- [experiment-plan](skills/experiment-plan/SKILL.md)：计算研究的主张、基线、消融与运行顺序；一般实验设计可考虑未部署的 [experimental-design 候选](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/experimental-design/SKILL.md)。
- [exploratory-data-analysis](skills/exploratory-data-analysis/SKILL.md)、[statistical-analysis](skills/statistical-analysis/SKILL.md)（按需）：数据质量与统计分析；具体软件实验由 Codex 在已授权范围内实现和运行。
- [scientific-visualization](skills/scientific-visualization/SKILL.md)、[scientific-writing](skills/scientific-writing/SKILL.md)（按需）：可追溯图表和论文／报告草稿；事实与引文依证据核实。
- [scientific-critical-thinking](skills/scientific-critical-thinking/SKILL.md)：对研究方法、数据解释和核心主张进行对抗复核。

## 汇报

- [presentation-making](skills/presentation-making/SKILL.md)：从材料与受众出发，设计逐页叙事、保留事实依据并检查成稿。
- [slides](skills/slides/SKILL.md)：制作可编辑 PPTX，保留生成源码，并渲染检查溢出、字体和版式。
- [slidev](skills/slidev/SKILL.md)（按需）：需要交互演示或代码讲解时制作网页幻灯片；不以其普通 PPTX 导出替代可编辑 PPTX。

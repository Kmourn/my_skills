# 任务续接与记忆

## 续接项目

先读用户指定的进展和现行项目入口，核对所选方案、实际运行和产物版本。中断时核对运行状态与可恢复断点，在已有授权、预算和停止条件内自行检查或续跑。

把重要决定、完成证据和下一步写回已有记录。现行状态过时就更新，历史快照保留当时的状态，按需链接最新记录。长任务的记录模板见 [planning-with-files](../../planning-with-files/SKILL.md)。

## 保存长期偏好

当前反馈直接用于当前任务，项目决定写回项目记录。涉及跨任务的个人偏好时，按需读取 Codex 主目录下已有的 `collaboration-memory.md` 或用户指定文件的相关条目。具体内容和适用范围确认后再保存。可复用方法按[主 Skill 的确认规则](../SKILL.md#阶段末确认与沉淀)提议或更新。

## 使用原生记忆

原生记忆可辅助回忆。任务状态和执行授权以当前指令及核实过的记录为准。需要配置时查对应客户端的[官方说明](https://learn.chatgpt.com/docs/customization/memories)。本机偏好、生成记忆、会话日志和凭据留在本机，框架仓库保存通用规则和模板。

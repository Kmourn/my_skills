# 方法图参考选择

优先使用用户指定、已授权或公开可取得的同类参考，比较承担相同解释任务的图。先明确本图需要读者理解的对象与关系，再选择参考；期刊名称、配色或网络模块外形不能替代这一判断。

- **共享计算或分支**：追踪输入、共享组件、分支和汇合点；确认图形是否区分参数共享与独立副本。
- **时序与状态**：追踪观测、状态更新、预测目标和执行时间，核对回路中的信息何时可用；有堆叠不代表存在持久状态。
- **机器人方法**：按实际任务表示状态、观测、动作与环境接口。只呈现方法中存在的感知、规划或语言模块；无需为领域观感补相机、实物照片或闭环。
- **总览与局部细节**：保持同一对象的符号和视觉角色，说明局部操作如何接回主干。

上游的 [参考索引](https://github.com/plbbl/academic-diagram-skill/blob/501efb0208bf865897079fa05844c249f0736077/references/README.md) 提供论文链接、图号及候选原尺寸图。按需要选取并打开实际图像，优先核对原论文；索引元数据不是已经独立核验的事实，不要求遍历整个图集。

上游的 [可编辑示例说明](https://github.com/plbbl/academic-diagram-skill/blob/501efb0208bf865897079fa05844c249f0736077/examples/README.md) 可帮助判断视觉组织。这些图是参考引导的重设计，不是盲测输出、原作者图或实验复现，仍需核对本次方法的科学关系。

将观察转成具体制作约束，如输入输出的对应、共享模块的位置、连线端点、颜色角色和留白。真实数值、模块、结论和实验图像仍来自本任务；参考图中的材料不自动进入新论文。缺少可访问参考时，说明未完成的风格对照，使用已有授权材料继续能完成的部分，不为取图新增服务或外发稿件。

本地包只保留来源链接，不包含第三方裁图、总览图或展示图。样稿及参考缓存留在任务允许的位置，不随 Skill 框架再次发布；详见 [素材说明](../THIRD_PARTY_NOTICES.md)。

# 写作参考

先定位本次样稿的文体、语言、受众及用户希望借鉴的部分。用户要求对齐经编辑、翻译或生成的样稿时，按该文本的实际特征工作；不替用户鉴定作者身份。

## 从样稿提取可复现特征

- **句法与节奏**：长短句组合，主被动、句首组织、并列与从属关系，段落展开方式。中文按分句、标点、话题推进观察；英文可观察从句、缩略形式和句式变化。跨语言分别归纳，不直接搬用词数或语法规则。
- **用词与语域**：具体词汇、术语密度、动词倾向、称呼、连接语及重复表达。引用少量短片段或给出段落／行号，证据不足时保持暂定，不将单次出现认作固定习惯。
- **修辞与结构**：开头如何进入主题，论点与例子的位置，因果或转折的组织，标题与列表，结尾的动作。区分文本内容与表达安排。
- **口吻与读者关系**：用可定位的表达说明直接或审慎、正式或口语、解释或评论的方式；不从文本推断私人身份、心理、价值观或经历。
- **限制与变化**：区分用户明确禁止的表达和“本组样稿未见”。没有出现不等于永不使用；一篇样稿不能支持跨文体的普遍规则。

将有代表性的观察转成可以检查的写作约束，如“先写本次结论，再用具体例子解释”，而不是“有灵魂”“像本人”等评价。保持用户要求的新题材和信息完整性，原样稿的故事、数字与观点不成为新内容来源。

## 生成或改写

同类样稿可共同定位稳定特征；邮件、论文、社交短文等差异明确时分开描述。用户要求混合参考时注明哪份负责结构、哪份负责口吻；无需品牌画像或其他未部署 Skill。

直接按规范完成本次稿件。改写时先确认应保留的事实、引文、术语和内容范围，再调整表达。科研稿件需要事实与引用核对时调用实际可用的 `scientific-writing`；不能因为参考风格就增加科研流程到普通文本。

## 对照实际文本

逐特征指出输出对应的句子或段落，检查是否因套用表面词汇而破坏论证或内容。量化句长或段长有助判断时，说明语言、计数方法及本次分布，容差由任务要求决定；不设固定样稿数量、统一数值阈值或固定通过次数。

若任务是提取供批量使用的规范，可在获准制作范围内用新内容试用，再修正已暴露的特征；用户只要规范时不自动增加代笔任务。最终判断表达是否符合用途，保留用户尚未审阅的口吻取舍，不以可观察特征匹配声称作者不可辨识。

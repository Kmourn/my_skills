# 图像参考

实际查看输入图像，再区分“以它为风格参考生成新主体”和“修改这张图”。对于可编辑 SVG、图标或原生绘图源文件，优先检查并修改已有源属性；位图生成与编辑调用当前可用的 `imagegen` Skill／工具。工具路径和参数以本次实际能力为准。

## 提取风格并标明参考角色

只选择对本任务有影响的视觉特征：

- 视点与构图：相机或观看角度、空间层次、主体相对位置、视线组织。
- 光影：光源方向、明暗层级、阴影边缘与环境光；由画面推断的光源属于估计。
- 配色：主色、强调色、饱和度、冷暖和明度关系。读取源色值时标为原生属性；从压缩截图取样得到的是画面色值，不等于原始设计色。
- 媒介与表面：线条、边缘、笔触、颗粒、纸张或材质呈现；只描述可见特征。
- 边框与平衡：裁切、留白、宽高比、对称或偏置、纹理和细节的分布。

分别列风格约束与目标内容。风格参考不自动要求复制原主体，主体参考不自动接管配色或构图；修改原图则明确保留项和变化项。颜色或材料如果是目标主体的必要特征，按用户要求保留，不因形式上的风格／内容拆分删除。

多图按角色编号，如“图一负责配色与笔触，图二负责主体形状，图三负责构图”。用户明确优先级时直接沿用。局部冲突先定位到具体特征，避免把整个参考当作必须复制的集合。

## 转换为制作输入

提示中写清目标主体、各参考作用、关键视觉约束、尺寸／透明度需求及不变项；保持精简，不沿用上游固定字符数。将参考实际传入可用工具，不能仅写“看起来像附件”却遗漏附件。本地图先查看，参考文件路径或会话图像的使用方法遵循当前 `imagegen` 工具及 Skill。

原生图形流程把观察映射为颜色、线宽、坐标、渐变、纹理及字号等源属性；需要可编辑输出时交付相应源文件。普通位图请求仍使用可用图像工具，原生流程不能替代用户所需的照片或插画效果。

不采用上游 Hermes／GenTube 路由、自动风格库、运行日志三件套或后台任务；不新增 provider 或读取凭据。能力不可用时交付已完成的规范，并说明尚未生成或检查的产物。

## 查看产物并对照

实际打开输出检查构图、光影、色彩、表面、留白以及保留项，说明具体符合处和偏差。透明背景要求检查实际透明度，含文字时核对文字。新主体中出现参考原主体或情节，先检查参考角色和提示是否混淆。

修正针对本次可见偏差，不用固定次数认定风格稳定。单张结果的对齐不能保证跨主体、跨会话一致；只有任务需要系列一致性时才比较系列实际产物。

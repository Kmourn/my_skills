# 数据图参考

参考样图提供视觉方式，数据和分析结果来自本次数据源。调用当前可用的 `scientific-visualization` 完成绘制、导出和目视检查；统计分析需求沿用本项目的分析流程。

## 确认图形与数据约束

读取已有绘图代码或原生图对象，定位数据路径、变量与单位、类别映射、排序、缺失值、过滤、聚合、轴尺度和不确定性定义。没有目标数据时可以交付样式规范；不能从参考像素补造数值来交付真实数据图。

将参考观察映射成局部视觉参数：字体与层级、颜色角色、线宽、标记、网格和边框、图例位置、留白、面板尺寸与间距、标签方式。截图中的像素字号或颜色标为估计，绘图源文件能直接读出的属性标为原生属性。

风格参数在临时样式上下文或当前图对象中设置，不修改全局配置。参考的刻度、轴范围、误差带或平滑曲线可能与本数据含义不兼容；样式不能默许更换这些统计或编码选择。需要改变时依据本次数据与任务明确处理，说明变化和理由。

## 保持并核对不变量

对于纯样式改动，前后核对实际相关的不变量：

- 输入记录、单位、类别对应及展示顺序，缺失和排除处理。
- 点位、统计估计、样本数量、区间数值与其定义。
- 过滤、归一化、分箱、平滑或拟合方法、随机种子。
- 轴变换、比例尺、颜色归一化和面积／长度编码。

比较源数据与绘图参数、图对象或输出底层数据；文件摘要可佐证源未变，但不能替代统计与映射核对。保留原始输入，避免为配色或构图隐藏不合视觉的点。

## 检查实际输出

查看最终尺寸的导出图，核对字体、颜色、线条、面板和标签与参考的对应关系，同时检查遮挡、裁切、误差含义及可读性。参考风格依赖颜色时，仍按数据语义和可访问性需要保留标记或线型等冗余提示。

交付图与必要源代码，并在已有记录中标明视觉参数变化及不变量的实际核对结果；没有运行统计或渲染的项目保留未检查状态。外观接近不代表数据正确或期刊要求通过。

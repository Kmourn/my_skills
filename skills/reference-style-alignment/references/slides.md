# PPT 参考

先判断参考和交付条件：可读取的 PPTX／原生模板，还是 PDF／截图；用户要在原文件中修改，还是制作内容不同的新 deck。两种参考支持的保留程度不同，必须与所需编辑性一起确定制作路径。

## 提取主题与布局家族

原文件可读取时检查实际主题、母版与布局关系、字体、尺寸、色值、占位符及对象属性；与渲染外观对应。截图或 PDF 用于观察宽高比、字体层级、标题位置、页边距、留白、色彩角色、分隔线、页码及图文比例；精确字体、母版关系和动画保持待定，不能从截图宣称已恢复。

将参考页分为任务需要的布局家族，如封面、章节、论点与证据、对照、全幅图及结尾。计划的新内容映射到适合的家族，不为追求相同版面删掉必要结论或改动数据。多参考分别承担主题、布局或图表样式，并说明冲突的处理优先级。

## 选择制作路径

- **原结构保留**：任务要求保留现有 masters／layouts／theme 时，先确认实际编辑路径能保留这些关系，再在原文件副本上修改并核对。当前工具只能重建时说明这一限制；不能将视觉重建称作原结构保留。
- **视觉重建**：只有截图，或用户接受重建时，匹配比例及可观察布局，用原生文本、形状和合适的图表对象实现所需编辑性。截图不能作为整页背景替代用户要求编辑的对象。

新 deck 或明显调整叙事时使用实际可用的 `presentation-making`；可编辑 PPTX 制作／重建使用 `slides`，遵循其当前制作和渲染工具。无需因为一次局部改字重跑整套规划。图像与数据图分别交由本 Skill 的相关分支及实际可用工具处理。

## 对照渲染和编辑性

渲染参考与输出，按对应页或布局家族检查宽高比、标题层级、字体替换、配色、对齐、留白、裁切、重叠与图文比例；完成 deck 时按制作 Skill 检查所有交付页。

编辑性另行检查实际源对象：文本仍是文本、需编辑的形状仍为形状、图表是否有原生系列及数据。可读取 PPTX 对象或打开实际编辑器确认所需对象；渲染检查本身不能证明可编辑。整张 SVG／图片置入的图表注明栅格／矢量资产范围，源代码可重建也不等于对象能在 PowerPoint 内逐项编辑。

原结构保留路径还需核对修改前后的主题、母版、布局关联及目标对象；只检查视觉相近不足以证明模板结构保留。交付原生文件和要求的可编辑源，说明截图估计、缺失字体或已扁平化的部分，未检查对象保留未验证状态。

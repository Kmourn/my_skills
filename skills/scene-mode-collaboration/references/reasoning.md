# 思考强度的选择与继承

思考强度是客户端或模型调用的运行参数。它与场景、协作模式、团队人数和回答长短分别决定；“认真思考”之类文字不能证明运行参数已改变。

## 默认与按需调整

沿用用户已选择的模型和思考强度。子智能体默认继承父智能体配置；需要不同配置时明确说明选择依据，并在用户指定或本阶段已选配置要求覆盖时设置实际参数。不要为了套用下表降低用户已有的强度。

没有既定偏好、需要提出选择时，可用以下本地建议；它们是任务判断参考，不是自动切换规则：

| 强度 | 适合考虑的任务 |
| --- | --- |
| `low` | 范围清楚的查看、提取、简单修改 |
| `medium` | 常规实现、资料整合和一般方案比较 |
| `high` | 跨组件设计、复杂排错、假设或证据链核查 |
| `xhigh` | 多种解释冲突、难以收敛的问题或较深独立复核 |
| `max`／`ultra` | 当前模型与客户端支持，且任务确实需要更多推理投入时 |

以任务难度和实测结果选择，避免把所有成员统一升到最高。证据缺失先获取证据，输入不清先澄清关键约束；更高强度不能替代这些工作。提高强度通常会增加时间与用量，其收益需要结合任务判断。[OpenAI 子智能体与思考强度说明](https://learn.chatgpt.com/docs/agent-configuration/subagents#choosing-models-and-reasoning)

## 实际设置与核对

- **主智能体：** 由客户端设置、有效 `config.toml` 或启动参数决定。修改配置后按客户端要求重新加载；不要声称文件修改已改变正在运行的本轮参数。
- **子智能体：** 默认继承；覆盖时使用派发工具实际提供的参数。某些工具的完整历史继承不支持模型或强度覆盖，按其真实限制选择上下文方式。
- **支持范围：** 查当前模型目录或客户端可用选项。`low`、`medium`、`high`、`xhigh`、`max`、`ultra` 并非所有模型与客户端都支持；不把 UI 标签、API 枚举与工具参数混用。
- **生效依据：** 能看到有效配置或工具返回值时据此报告；只提交了请求或写了配置时，分别称为请求值或已写配置。无法读取实际运行强度时说明未知。

当前 Codex 的根配置键为 `model_reasoning_effort`；`[agents]` 可以设置 `default_subagent_reasoning_effort`。不设置子智能体覆盖时通常继承父配置；显式切换子模型却没有指定强度时可能使用该模型默认值，自定义成员文件还可以覆盖已解析的值。因此切换模型时需同时核对强度兼容性。[OpenAI 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)、[OpenAI 继承规则](https://learn.chatgpt.com/docs/agent-configuration/subagents#custom-agents)

例如用户明确选择“主智能体 high、子智能体 medium”时，将以下值合并到已有配置的对应位置：

```toml
model_reasoning_effort = "high"

[agents]
default_subagent_reasoning_effort = "medium"
```

根键必须放在根区段，表内键放在对应表；不要直接追加重复的 `[agents]` 或覆盖其他配置。自定义成员文件及派发参数还会影响最终配置，需核对结果。部署本 Skill 不会改写模型或强度设置；`ultra` 也不改变本框架对派发指令和任务授权的要求。

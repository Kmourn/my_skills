# 本地 PDF 工具与检查

这些是按需示例，不要求每项任务依次执行。先核对现有程序与 Python 环境，只选当前任务需要的工具。

## 提取与渲染

命令中的 `pdf_input`、`pdf_text` 和 `pdf_render_prefix` 是已核对的任务路径；所有输出及临时目录须位于当前用户实际主目录，含空格的路径使用引号。

```bash
pdfinfo "$pdf_input"
pdftotext -layout "$pdf_input" "$pdf_text"
pdftoppm -f 1 -l 2 -r 120 -png "$pdf_input" "$pdf_render_prefix"
```

页码范围按任务与改动选择。长文档可先看首页、关键表图、章节与分页边界，再检查出现问题的页面；没有检查的页面不报告为已通过。用实际可用的图像查看工具打开渲染图，核对页眉页脚、对齐、可读性和裁切，不能仅凭 PNG 文件存在就宣称视觉通过。

`pdftotext` 能满足普通文字提取时，不必为此安装 Python PDF 包。`pdfplumber` 可辅助定位文本与表格；`pypdf` 适合页面拆合与元数据处理。遇到扫描件或提取顺序异常，结合原页核对；OCR 或复杂表格识别只在当前任务确实需要且有可用能力时采用，并标明识别不确定处。

## 生成与字体

`reportlab.platypus` 的 `Paragraph`、`Table`、`SimpleDocTemplate` 可处理普通报告的换行和分页。保留项目已有源文件和生成路径，不为得到 PDF 重建已有文档流程。

- 使用文档所需字体覆盖；需要 Unicode 时优先选择已有可用字体并检查嵌入或替换结果，不将所有标点强制改为 ASCII。
- `Paragraph` 接受标记文本；把原始资料中的 `&`、`<`、`>` 等字符作为普通内容时先转义，避免意外改变排版。
- 表格说明单位、来源，长表按需重复表头；图与数值从当前任务实际素材或数据生成。验证小样中的合成值须明确标为测试资料，不能混入研究结论。

## 依赖缺失时

先检查运行环境；优先复用项目虚拟环境、已有 Poppler 和工具替代。安装必须位于用户实际主目录，不写系统路径。以下只适用于任务确需该包、安装属于已授权范围的情况：

```bash
python3 -m venv "$pdf_venv"
"$pdf_venv/bin/python" -m pip install reportlab
```

`pdf_venv` 为已核对的用户目录内路径；只安装实际选用的包，需要表格提取或拆合时再选择 `pdfplumber` 或 `pypdf`。创建环境或安装所需的临时目录、缓存也放在用户目录内，可按项目约定设置 `TMPDIR`、`PIP_CACHE_DIR`；绘图需要时同样设置 `MPLCONFIGDIR`。工具不可安装时报告缺失项和影响，提供可执行的人工检查方法，不运行管理员安装命令。
